# ASIC Economics

An interactive, normalized design-space model for exploring the relationships among AI ASIC die area, MAC count, voltage, power, sustained FLOPS, memory bandwidth, and token throughput.

The dashboard is an explanatory first-order model rather than measured Etched, Cerebras, or foundry silicon data. Its assumptions and limitations are documented at the bottom of the page.

## Run locally

Open `index.html` directly in a modern browser. The dashboard has no external runtime dependencies or build step.

## Deployment

The `main` branch is published with GitHub Pages.
