# ASIC Economics

An expanding collection of interactive models for exploring AI compute from silicon design through system performance to unit economics.

## Explorations

- [`/lvi-design-space/`](./lvi-design-space/) — a normalized first-order model of AI ASIC die area, MAC count, voltage, power, sustained FLOPS, memory bandwidth, and token throughput.

The LVI dashboard is an explanatory model rather than measured Etched, Cerebras, or foundry silicon data. Its assumptions and limitations are documented at the bottom of the page.

## Run locally

Open `index.html` directly in a modern browser. The site has no external runtime dependencies or build step.

## Deployment

The `main` branch is published with GitHub Pages.
